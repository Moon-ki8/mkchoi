This project is about the computational infrastructure that makes atomistic modeling reproducible and scalable.
Rather than focusing only on one material system, it addresses the software layer needed to define, compare, and deploy force-field models consistently.

That includes clean parameter typing, interoperable workflows, and practical tooling for simulation campaigns that need to remain maintainable as models and datasets evolve.

## Focus

- Type-label and force-field infrastructure in LAMMPS
- Reproducible workflows for interatomic model deployment
- Software patterns for scalable simulation studies
